transformer_lens.tools.analysis.interchange module¶

Interchange interventions on linear subspaces.

An interchange intervention runs the model on a base input while setting the base’s activation at one hook point, inside a subspace, to its value on a source input:

h' = h_base + strength * (h_source - h_base) @ B @ B.T

B is an orthonormal [d_model, rank] basis, the convention of orthonormal_subspace(). The base keeps its own coordinates outside the subspace. If the model then produces the output a high-level causal model predicts for the base with one variable taken from the source, the subspace carries that variable at that hook point (Geiger et al., 2021).

The module provides the intervention, fixed-direction bases to intervene on (the difference of class means, a linear probe’s weights, a random basis), and a norm-matched random-subspace placebo. neuron_basis() turns a set of MLP neurons, such as the features a sparse probe selects, into a basis, and random_neuron_basis() draws random neurons as its placebo. fit_das() learns the basis instead, by distributed alignment search (DAS; Geiger et al., 2024): it trains an orthonormal basis so that the interchange produces the high-level model’s predicted outputs.

An interchange accuracy is not evidence on its own. DAS fits arbitrary label mappings and finds effects in randomly initialised models (Arora et al., 2024), so the module also provides the controls to train the same way: arbitrary_targets() for an arbitrary-label control, and random_init_bridge() or reinitialized() for an untrained copy of the model. Compare a learned subspace with both, and with the placebo and the baselines.

Works with any model exposing the hook API (TransformerBridge or a HookedRootModule). Activations at the hook must be [batch, d_model], or [batch, pos, d_model] with one position index per example.

transformer_lens.tools.analysis.interchange.fit_das(model: Any, hook_name: str, base_inputs: Tensor, source_inputs: Tensor, targets: Int[Tensor, 'batch'], task_logits: Callable[[Tensor], Float[Tensor, 'batch n_classes']], *, rank: int, base_positions: Int[Tensor, 'batch'] | None = None, source_positions: Int[Tensor, 'batch'] | None = None, epochs: int = 20, batch_size: int = 128, lr: float = 0.01, strength: float = 1.0, seed: int = 0, device: str | device | None = None, micro_batch_size: int | None = None) → DASResult¶

Learn the subspace whose interchange makes the model output targets (DAS).

targets[i] is the class the high-level causal model predicts for base i with the aligned variable set to its value in source i. The basis is trained with cross-entropy on the task logits under the interchange. Model parameters are frozen during the call and their requires_grad flags restored afterwards.

Train on pairs where several variables differ between base and source, labelled by the high-level model’s interchange, as well as on pairs that differ only in the aligned variable: otherwise the subspace can learn whatever the pairs happen to move together.

Parameters:

  • model – A model exposing the hook API.

  • hook_name – The hook point to align.

  • base_inputs – Base inputs, one row per pair.

  • source_inputs – Source inputs, one row per pair.

  • targets – The high-level model’s output class for each pair under the interchange.

  • task_logits – Runs the model on a batch of inputs and returns task logits.

  • rank – Dimension of the subspace.

  • base_positions – For [batch, pos, d_model] activations, the base position per pair.

  • source_positions – Likewise for the sources.

  • epochs – Passes over the pairs.

  • batch_size – Pairs per optimisation step.

  • lr – Adam learning rate.

  • strength – Interchange strength during training.

  • seed – Seed for the basis initialisation and the batch order.

  • device – Device for the subspace’s parameters; by default the device of the model’s parameters, or the CPU for a model without any.

  • micro_batch_size – Split each batch into parts this size and accumulate gradients: the same gradients, up to floating-point rounding, in less memory.

Returns:

The learned subspace with its training losses.

Raises:

ValueError – If any part of the model is in training mode, or the inputs and targets differ in length.

Interchanging it sets exactly those neurons to the source’s values, at a neuron hook such as blocks.N.mlp.hook_post. Compare it with random_neuron_basis() of the same size: a random direction is the wrong placebo for a claim about neurons, because it spreads over every neuron.
